# Figma 사본 만들기

`docs/design-system/`의 토큰과 컴포넌트 미리보기를 Figma 파일 하나로 내보내는 스크립트입니다. 방향은 레포에서 Figma 한쪽뿐입니다. Figma에서 고친 것은 돌아오지 않으니, 값은 레포에서 고치고 여기를 다시 돌립니다.

Figma의 플러그인 API를 브라우저 편집기 안에서 직접 부릅니다. Figma MCP는 스타터 플랜의 호출 한도가 작아서 쓰지 않습니다.

## 만드는 것

- 변수: `Color · Light`, `Color · Dark`(색 토큰, 같은 이름), `Size`(간격·반경·크기·불투명도·폭 기준).
- 스타일: 글자 스타일(`type`), 그림자 스타일(`shadow`).
- 페이지: 시작, 색, 글자, 간격 · 모양, 그리고 컴포넌트 묶음마다 한 페이지.
- 컴포넌트: 미리보기(`components/<이름>/preview.html`)를 브라우저에서 그린 뒤 위치·색·글자를 읽어 레이어로 옮깁니다. 캡션(`q-cap`)이 붙은 상태 하나하나가 Figma 컴포넌트가 됩니다.

## 돌리기

1. 서버를 띄웁니다. 이 Mac 안에서만 열리고(127.0.0.1:8765), 끝나면 끕니다.

   ```bash
   python3 docs/design-system/tools/figma/server.py
   ```

2. Chrome에서 `http://127.0.0.1:8765/walk.html`을 엽니다. 탭 제목이 `walk done`이 되면 레이어 정보가 임시 폴더에 저장된 것입니다. 미리보기나 `bundle.css`를 고쳤으면 다시 엽니다.
3. Chrome에서 대상 Figma 파일을 편집 권한으로 엽니다.
4. 그 탭의 개발자 도구 콘솔에 `console.js`의 내용을 붙여 넣습니다. 스크립트 여섯 개가 차례로 돌고, 각자 만든 개수를 찍습니다.

하나만 다시 돌릴 때는 콘솔에서 `await quillRun('2_color.js')`처럼 부릅니다. 중간에 실패하면 전에 만든 판은 그대로 남습니다. 컴포넌트 묶음 하나만이면 먼저 `window.quillArg = { group: '2 · 분자' }`를 넣습니다.

## 다시 돌리면

- 변수와 스타일은 이름으로 찾아 값을 덮어씁니다. 토큰을 지워도 Figma의 변수는 지워지지 않으니 손으로 지웁니다.
- 페이지마다 새 판을 다 만든 뒤 전에 만든 판(페이지와 같은 이름의 프레임)을 지웁니다. 그 판 안에서 손으로 고친 것과, 거기 있던 컴포넌트를 쓴 인스턴스의 연결은 사라집니다. 다른 프레임과 다른 페이지는 건드리지 않습니다.

## 알아 둘 점

- **라이트·다크가 컬렉션 두 개입니다.** 스타터 플랜은 변수 모드가 하나라서 나눴습니다. 컴포넌트 그림은 라이트 값에만 연결됩니다.
- **글꼴을 바꿔 그립니다.** SF Pro와 SF Pro Rounded는 Figma 브라우저 편집기에서 그려지지 않아 Pretendard로, SF Mono는 Menlo로 그립니다(`lib.js`의 `FAMILY`). 미리보기도 같은 글꼴로 그린 뒤 읽으므로 자리는 맞지만, 글자 폭은 실제 앱과 조금 다릅니다. Pretendard가 이 Mac에 깔려 있어야 합니다.
- **레이어는 고정 위치입니다.** 오토 레이아웃이 아니라서 글자를 바꿔도 주변이 따라 움직이지 않습니다. 눈으로 보는 사본이고, 화면을 새로 짤 때 쓰는 부품은 아닙니다.
- **토큰 연결은 미리보기가 `var(--토큰)`으로 쓴 색만입니다.** `color-mix`로 섞은 색과 CSS에 직접 적은 색은 값만 들어갑니다. 반경은 값이 같은 토큰에, 글자는 종류·크기·굵기·자간이 같은 스타일에, 그림자는 값이 같은 스타일에 붙입니다.
- 표지(`components/Cover`)는 옮기지 않습니다. `conic-gradient` 도넛은 같은 모양의 SVG로, 회전한 테두리로 그린 체크는 SVG 체크로 바꿔 그립니다.

## 파일

| 파일 | 하는 일 |
| --- | --- |
| `server.py` | 이 폴더와 `tokens.json`, `components/`를 Figma 탭이 읽게 내주고, `walk.html`이 보낸 레이어 정보를 임시 폴더에 받습니다. |
| `walk.html` | 미리보기를 한 번은 실제 색으로, 한 번은 토큰마다 다른 표시 색으로 그려서 어느 색이 어느 토큰인지까지 읽습니다. |
| `console.js` | Figma 탭 콘솔에 붙여 넣는 실행 줄. |
| `lib.js` | 색·그림자 읽기, 글꼴 대응, 판과 글자를 만드는 도우미. |
| `1_tokens.js` | 변수, 글자 스타일, 그림자 스타일. |
| `2_color.js` – `5_start.js` | 색, 글자, 간격 · 모양, 시작 페이지. |
| `6_components.js` | 컴포넌트 페이지와 페이지 순서. |
