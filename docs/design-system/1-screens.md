# 화면 구성 (macOS)

macOS 앱의 모든 화면과 그 안의 영역을 컴포넌트·토큰 이름으로 적었습니다. 새 화면을 만들거나 다른 플랫폼으로 옮길 때 이 구조를 기준으로 삼습니다. 미리보기는 컴포넌트의 **4 · 화면 · macOS** 묶음에 있습니다.

## 1. 메뉴 막대

- 메뉴 막대 아이콘 → 표준 NSMenu. 최근 전사, 오디오 입력 하위 메뉴, 단축키별 "Customize…", 설정, 설정 다시 실행, 업데이트 상태 줄.
- 시스템 메뉴 모양을 그대로 씁니다. 별도 스타일 없음.

## 2. 녹음 오버레이 (화면 위, 항상 검정)

| 상태 | 내용 | 폭 |
| --- | --- | --- |
| 준비 중 | 점 셋이 차례로 밝아짐(`InitializingDotsView`) | 92 |
| 녹음 중(누르고 있기) | 9개 흰 파형 막대 | 92 |
| 녹음 중(토글) | 파형 + 오른쪽 빨간 정지 원(`size-close`) · 클릭하면 입력 전환 메뉴 · hover하면 경과 시간 | 150 |
| 편집 모드 | 왼쪽 연필 아이콘 + 파형 | 180 |
| 처리 중 | 5개 알약 펄스 → 1초 뒤 도는 링 | 92 |
| 오류 | 빨간 오류 아이콘 + 한 줄 문구 | 가변 |
| 업데이트 | 다운로드 아이콘 + "버전 x 사용 가능" | 190 |

- 배치: **가운데**(노치 아래 알약) 또는 **노치 옆**(노치 좌우로 92pt씩 확장). 높이 `size-overlay-height`.
- 알림 토스트: 오버레이 아래 별도 패널, `overlay-surface` + `radius-10`.
- 회의 알림: 노치에서 내려오는 검정 패널(`radius-26`), 앱 아이콘·이름·닫기 / 회의 이름·시작 시각·흰 "시작" 캡슐.

## 3. 노트 브라우저 (주 창)

미리보기: **4 · 화면 · macOS › MacNoteBrowser**

- **사이드바 머리**: 첫 줄은 신호등 버튼과 같은 줄에 `IconButton` 두 개(검색, 오디오 가져오기)와 `선택` `CapsuleButton`(선택 중에는 `완료`). 둘째 줄은 `InputPicker`(66×26) + `ModelPicker`(남은 폭). 검색을 열면 둘째 줄이 `SearchField`로, 선택 모드에서는 선택 개수 + `모두 선택`으로 바뀌어 머리 높이는 그대로입니다. 머리는 반투명 재질이고, 목록이 밑으로 스크롤되면 아래 0.5 구분선이 나타납니다.
- **목록**: `NoteListRow` 80pt, 행 사이 여백 없이 `radius-8` 행. 다중 선택 시 왼쪽에 `SelectionCheckbox`, 오른쪽 상세 영역은 `NoteMultiSelectionPanel`.
- **녹음 버튼**: 사이드바 아래 가운데, 44pt 원. 대기 `status-recording`, 녹음 중 `status-processing` + 흰 정사각형.
- **삭제 캡슐**: 녹음 버튼 위, 유리 캡슐 + 줄어드는 취소 버튼.
- **상세 머리**: 좌우 `space-40`, 위 32. 날짜 줄(SF Mono 10 `label-tertiary`, 예: 2026년 10월 24일 (토) 오전 9:56 + `Badge` 태그 `CLOUD · CTX · LLM · 언어`) → 제목(28 Bold, 바로 고치기, 0.5초 뒤 저장) → [캘린더 제목 제안 줄] → `AudioPlayer`(오디오가 있을 때). 아래에 구분선.
- **상세 본문**: 가운데 세그먼트(`전사문` / `요약`, 작은 크기, 요약이 있을 때만) → `StatusBanner` → 본문(`transcript`). 아래 가운데에 `NoteToolbar`가 떠 있습니다(녹음 중인 노트, 비교 중에는 숨김). 빈 노트는 `IssueEmptyState`.
- **빈 상태**: 노트 없음(`mic`), 검색 결과 없음(`magnifyingglass`), 문서 없음(`doc.text`). 모두 80pt 원 + ultraLight 아이콘 + `empty-title` + `callout`.
- **토스트**: 하단 가운데 `NoteBrowserToast`.

## 4. 설정 창

미리보기: **4 · 화면 · macOS › MacSettings**

- 사이드바: `SettingsSidebarRow`(아이콘 13 + `body`, 위아래 8, 좌우 10), 선택 탭은 `accent-tint-nav` + `radius-6`. 스크롤하지 않습니다. 개발 빌드에만 실행 로그·디버그 탭.
- 페이지: `SettingsPageScrollView` 안에 `SettingsCard`를 세로로 쌓습니다. 첫 카드는 창 위에서 40pt.
- 카드 안 규칙: 피커는 위에 `caption` semibold 라벨 + 아래 280~320pt 컨트롤, 도움말은 `caption` + `label-secondary`, 주의는 주황 삼각형 + `caption`, 오류는 `QuillUserIssueView` inline. 펼쳐 보는 항목은 `› 세부 설정` 같은 접기 줄.
- 켜기/끄기: 카드 안의 옵션 하나는 **체크박스**(로그인 시 실행, 업데이트 자동 확인, 알림 소리 재생, 회의 전 녹음 알림). 기능 전체를 켜고 끄는 것은 **스위치**(전사·후처리·컨텍스트·회의 요약은 카드 머리 오른쪽, 명령 보호·iCloud 동기화·AI 도구는 그 줄 오른쪽).
- 여럿 중 하나 고르기: `OptionRow`를 세로로 쌓습니다(오디오 소스, 마이크, 단축키, 오버레이 배치·파형 표시). 항목이 짧으면 가로로 나란히(회의 알림 시간).
- 권한 줄: `surface-control` + `radius-6`, 안쪽 10, 왼쪽 파란 아이콘, 오른쪽에 초록 체크 + "허용됨" 또는 `접근 허용` 버튼.

## 5. 온보딩(설정 마법사)

- 최소 560×600, `surface-window`. 큰 제목 `setup-hero`/`setup-title`(SF Rounded Bold), 선택 카드는 `surface-control` + 선택 시 `accent-tint-selected`, 아래 이전/다음 버튼. 권한 안내 창은 반경 14 카드(단계 밖 값, 정리할 곳 5번).
