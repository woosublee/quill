# Note Browser 요일 포함 타임스탬프 설계

**작성일:** 2026-08-11\
**상태:** 승인됨 — 구현 계획 작성 전 명세 검토 필요

## 목표

Note Browser에서 노트가 만들어진 녹음 시점을 더 빠르게 구분할 수 있도록 요일을 함께 표시한다. 한국어 사용자는 다음 형식을 본다.

- 좌측 목록: `8월 10일 (월) 오전 10:00`
- 우측 상단 녹음 정보: `2026년 8월 10일 (월) 오전 10:00~11:12`

기존의 오전/오후 표기는 유지한다.

## 범위

### 포함

- 좌측 노트 목록의 날짜·시간 라벨에 현지화된 요일을 추가한다.
- 우측 노트 상세 헤더의 단일 시각 또는 녹음 구간 표기에 현지화된 요일을 추가한다.
- 유효한 녹음 시작·종료 시각이 있을 때와 없는 과거 노트 모두를 지원한다.
- 한국어, 영어, 일본어 등 현재 시스템 로케일별 날짜 순서와 요일 표기를 유지한다.
- 날짜를 넘기는 녹음은 시작일과 종료일 각각에 해당 요일을 표시한다.

### 제외

- `PipelineHistoryItem` 저장 구조, 기존 노트 데이터, 녹음 시간 산정 방식 변경
- 목록 행 높이·글꼴·색상 등 레이아웃 변경
- 사용자가 날짜 형식을 직접 설정하는 환경설정 추가

## 설계

### 단일 포맷터 경로

`Sources/NoteListRowDisplayData.swift`의 `NoteTimestampFormatter`를 모든 표시 형식의 단일 책임 지점으로 유지한다. `NoteListRowDisplayData`와 `NoteDetailView`는 계속 각각 `rowTimestamp`와 `detailTimestamp`만 호출한다.

포맷터는 Foundation의 로케일 템플릿 API를 사용한다.

| 용도 | 입력 | 템플릿 필드 | 한국어 예시 |
| --- | --- | --- | --- |
| 목록 | `recordingStartedAt`, 없으면 `timestamp` | 월·일·요일·시간·분 | `8월 10일 (월) 오전 10:00` |
| 상세 단일 시각 | `timestamp` | 연도·월·일·요일·시간·분 | `2026년 8월 10일 (월) 오전 10:00` |
| 상세 녹음 구간 | `recordingStartedAt`~`recordingEndedAt` | 연도·월·일·요일·시간·분 | `2026년 8월 10일 (월) 오전 10:00~11:12` |

목록은 `DateFormatter.setLocalizedDateFormatFromTemplate("MMMMdEEEjm")`을 사용한다. 상세 단일 시각과 유효한 녹음 구간은 각각 `DateFormatter`와 `DateIntervalFormatter`에 `"yMMMdEEEjm"` 템플릿을 설정한다. 상세 템플릿의 `MMM` 필드는 한국어에서 요일을 괄호로 묶는 시스템 표기를 보장하며, 영어에서는 `Aug`처럼 표준 축약 월 이름을 사용할 수 있다. 템플릿은 날짜 구성 요소의 언어별 순서와 구두점을 Foundation에 맡기므로 영어와 일본어도 해당 로케일의 관례에 맞는 요일 표기를 얻는다.

### 상세 헤더의 구간 처리

기존과 같은 유효성 조건을 유지한다.

1. 시작·종료 시각 둘 다 존재하고 종료가 시작보다 빠르지 않으면, `DateIntervalFormatter`로 구간을 표시한다.
2. 조건에 맞지 않으면 `timestamp` 한 개를 단일 시각 형식으로 표시한다.
3. 날짜를 넘긴 구간에서는 포맷터가 양 끝의 날짜와 요일을 모두 표시한다. 예: `2026년 8월 10일 (월) 오후 11:40 ~ 2026년 8월 11일 (화) 오전 12:10`.

시간제는 별도로 강제하지 않는다. 사용자가 선택한 대로 한국어에서 기존의 오전/오후 표기를 유지하고, 다른 로케일도 시스템 관례를 따른다.

### 공백 정규화

현재 `normalized(_:)`가 처리하는 non-breaking space, narrow no-break space, thin space 정규화는 유지한다. 이는 로케일 포맷터가 반환하는 화면상 동일한 공백을 테스트 결과와 안정적으로 비교하기 위해 필요하다.

## 테스트

`Tests/NoteListRowDisplayDataTests.swift`의 포맷 테스트를 갱신하고 다음을 보장한다.

1. 한국어 목록 표기가 요일과 오전/오후를 포함한다.
2. 영어·일본어 목록 표기가 각 로케일의 요일 형식을 사용한다.
3. 한국어 상세 단일 시각과 같은 날 녹음 구간에 요일이 포함된다.
4. 오전에서 오후로 넘어가는 구간의 오전/오후 표시가 유지된다.
5. 날짜를 넘기는 구간에서 시작·종료 날짜 각각에 올바른 요일이 포함된다.
6. 목록은 계속 녹음 시작 시각을 우선하고, 시작 시각이 없는 항목은 `timestamp`를 사용한다.

관련 단위 테스트와 전체 core 테스트 대상(`make test-core`)을 실행한다.

## 완료 기준

- 한국어 목록이 `8월 10일 (월) 오전 10:00` 형식으로 보인다.
- 한국어 상세 헤더가 단일 녹음 또는 녹음 구간에서 날짜·요일·시간을 함께 보인다.
- 기존 노트와 날짜를 넘기는 녹음이 안전하게 표시된다.
- 로케일별 테스트와 core 테스트가 통과한다.
